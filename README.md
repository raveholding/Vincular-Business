# Vincular Business

Sitio comercial de Vincular Business (since 2022 ★★★): sistemas, digitalización y productos NFC para todos los rubros.

- `index.html`: la web completa en un solo archivo (CSS y JS incluidos). Se abre directo en el navegador.
- `assets/`: logos. `logo-web` (horizontal) e `icon-app` (ícono para la app y perfiles de redes, SVG y PNG 512/1024).

Precios, contacto y listas de módulos se editan en el objeto `CONFIG` al inicio del script de `index.html`.
